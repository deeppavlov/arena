# Артефакты

Воспроизводимые пакеты кандидатов, разрешённые train-индексы и отчёты, граф происхождения и кривые эволюции train/public. Большие файлы храни во внешнем разрешённом хранилище, здесь фиксируй digest и ссылку. Закрытые public/private данные, логи, ответы и секреты здесь не хранятся. Исторические артефакты не переписываются при изменении протокола.

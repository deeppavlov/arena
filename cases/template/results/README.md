# Результаты

Записывай публичные замеры, состав подвыборки, hashes кандидатов, версии условий, ссылки на MLflow и обоснование отбора. Для каждого кандидата обязательны `score`, `solver_tokens`, `solver_seconds`, `solver_unreported_attempts`; аналогичные судейские затраты хранятся отдельно с префиксом `judge_`. Расход неполон, если были попытки без usage; не выдавай его за нулевой или точный. Screening и полный замер обозначаются раздельно. Из private сюда попадает только разрешённый итог после завершения всей серии, без ответов и оценок отдельных примеров.

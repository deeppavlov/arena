# Встроенная модельная метрика

`metric.json` использует готовый профиль оценки по эталону. Заполни `instruction`, критерии и веса под задачу. `votes` задаёт положительное число независимых оценок каждого критерия; в примере оно равно 3. Итог критерия — среднее оценок 1–5, итог примера — взвешенное среднее критериев, итог набора — среднее примеров, если не задана другая агрегация.

Выбери эту папку как источник для `evaluator.prepare freeze`, если правила профиля подходят кейсу. Иная шкала, несколько этапов, программные проверки или другая схема судейства реализуются [своей командой](../custom-model/README.md). Перед заморозкой нужны синтетические проверки с подставными ответами; обращение к реальной модели — отдельный явно разрешённый эксперимент.

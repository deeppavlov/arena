# Public

Здесь размещают только разрешённую публичную часть и её manifest: версия, происхождение, состав, правила split, digest и версия синтетических эталонов. Формат `examples.jsonl` описан в README кейса. Данных в шаблоне нет.

Полный private находится только у оператора оценщика. Не копируй его сюда даже временно и не коммить его зашифрованную копию или отдельные ответы.

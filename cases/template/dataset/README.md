# Данные

Manifest описывает версии, происхождение, размеры и правила разделения трёх частей: train, public и private. Состав split фиксируется до кампании. Любая часть, включая private, может содержать ноль примеров; размеры задаются постановкой, пустая часть не подменяется другой и не получает выдуманную оценку.

| Часть | Что доступно исследователю |
| --- | --- |
| Train | Разрешённые данные, ответы, оценки и трейсы; можно делать свои разбиения и анализ ошибок |
| Public | Только итоговый score кандидата через оценщик |
| Private | Только статус обработки финального пакета; результаты смотрит оператор |

Здесь хранят только разрешённые train-данные и manifest без закрытого содержимого. Формат JSONL описан в README кейса. Данных в шаблоне нет. Для миграции прежний доступный исследователю public становится train с явной новой версией описания; исторические артефакты не переписываются.

Закрытые public/private находятся у оператора оценщика. Не копируй их сюда даже временно, не коммить зашифрованные копии, ответы или трейсы. Для пустого public или private соответствующий оценщик не требуется. Без private итоговый выбор фиксируется по условиям кампании и доступным свидетельствам, без закрытого ранжирования.

# Уточнения кейса

Здесь дополняют общие промпты из `prompts/`: задача, допустимые изменения, особенности материалов и проверяемые гипотезы. Укажи явно, фиксированы ли харнес и его параметры. В режиме поиска харнеса зафиксируй остальные компоненты решения и разрешённый реестр; в режиме поиска самого решения зафиксируй харнес. Не привязывай общий протокол к конкретным именам харнесов или последовательности кампаний.

Не копируй всю общую методологию. Фиксированные модель, split, метрика, эталоны и границы train/public/private сохраняются. Возможность решения и оценки без LLM задаётся задачей.

# Уточнения кейса

Здесь дополняют общие промпты из `prompts/`: задача, допустимые изменения, особенности материалов и проверяемые гипотезы. Для компонентов решения, выбора харнеса и его параметров отдельно укажи, что фиксировано, а что участвует в эволюции. Можно разрешить изменение одного компонента или совместный поиск нескольких. Разрешённый реестр харнесов фиксируется до кампании. Не привязывай общий протокол к конкретным именам харнесов или последовательности кампаний.

Не копируй всю общую методологию. Фиксированные модель, split, метрика, эталоны и границы train/public/private сохраняются. Возможность решения и оценки без LLM задаётся задачей.

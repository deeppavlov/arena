# Исходные предложения для SC-71

В [`original/`](original/README.md) сохранена исходная папка `artifacts/sc-71-candidates`: семь предложений методов, общая библиотека `retrieval/`, адаптер, скрипты, настройки, зависимости, документация и синтетические тесты. Все 134 файла скопированы без изменения байтов и внутренней структуры. [`manifest.json`](manifest.json) содержит размер и SHA256 каждого файла.

Это материалы для новых гипотез, а не зарегистрированные решения и не часть универсального ядра арены. Их сохранение не расходует бюджет кампании и не подтверждает совместимость с текущим runner. Перед оцениванием метод нужно адаптировать к условиям кейса и зарегистрировать как решение.

Сначала читай [условия SC-71](../README.md) и [предложения для кампании](../prompts/proposal.md). Они имеют приоритет над исторической методологией и настройками в `original/`: фиксированы Hermes и профиль модели; ранжированный поиск подключается как обязательный инструмент Hermes; файловый агент ищет через предоставленную файловую систему. Создание любого представления KB, включая SQLite, относится к методу и учитывается во время поиска. Старые рекомендации заранее подготовить индексы, конкретные пути на GPU6, прежний адаптер подготовки контекста и параметры моделей не являются условиями новой кампании.

В копии нет реальной базы знаний, датасета, эталонов, индексов, весов, секретов или файлов результатов. `examples/` и фикстуры тестов искусственные; это явно указано в исходной методологии и документации методов. `RESEARCH.md` сохранены как исторические описания гипотез и ограничений. Исходники не форматировались и не исправлялись: `original/` исключается из стандартных проверок кода арены; его тесты остаются рядом с соответствующими предложениями для отдельного запуска.

# Локальный адаптер Arena

Контракт: commit `4858f0bf02c3766b84d8dd4bce7810390b9028bc`, прочитан 18.10.2026.
Это реализация формата подготовки контекста; развёрнутая Arena здесь не проверена.

Вход через stdin:

```json
{"input":"Кто согласует закупку?","assets_dir":"/assets","parameters":{"candidate":"bm25_sections","index":"indexes/bm25_sections"},"model":"OPERATOR_MODEL","model_base_url":"OPERATOR_CAPABILITY_URL","model_request_timeout":600}
```

`parameters` дополняет `selection.json` экспортированного пакета. Для гибридов
нужен относительный путь `embedding_model` к заранее размещённым в `/assets` весам.
Индекс должен быть построен с `embedding_backend=local`. Настройки нарезки,
ранжирования, агентов и контекста берутся из индекса и остаются прежними.

Выход: один JSON `{"context":"..."}`. Контекст содержит вопрос, исходные
доказательные участки и ссылки в том же формате, что общий генератор кандидатов.
`prompt.md` содержит прежнюю инструкцию генератора. Runner выполняет финальную
генерацию; адаптер её не дублирует. Отдельный `scripts/prepare.py` здесь не вызывается.

Ограничения: оператор должен установить необходимые зависимости в image и
смонтировать assets. Дополнительный HTTP-эмбеддер/reranker не разрешается этим
адаптером автоматически. Планировщик и агент обращаются только к gateway из stdin;
capability URL не помещается в env или диагностику. Нет автоматической установки,
скачивания весов, серверных изменений, отправки финалистов или официальной оценки.

# linked_hybrid

Гибрид плюс обход явных ссылок, подтверждённых исходным текстом.

Рабочий пакет импортирует общую библиотеку `retrieval/`. Переносимый экспорт с этой библиотекой создаёт `scripts/export.py`. `candidate.json` описывает прежний локальный build/run интерфейс; алгоритм и параметры — в `settings.json`, конфигурация сохраняется в build.

```bash
python build.py --kb-dir /kb/norm --build-dir /build
python run.py --build-dir /build --question 'Кто согласует закупку?' --format json
python run.py --build-dir /build --question 'Кто согласует закупку?' --answer-mode llm
```

По умолчанию answer-mode=extractive: выдаёт выдержки, а не полноценное решение. Для Q&A нужен общий внутренний LLM-сервис и `--answer-mode llm`. Двум гибридам нужен эмбеддер: предварительно загруженные локальные веса либо разрешённый внутренний сервис. Настройка, ограничения и проверенный объём описаны в общем README, который следует передавать вместе с пакетами.

`requirements.lock` фиксирует прямые зависимости HTTP-профиля. Для local-профиля есть `requirements-local.txt`; транзитивные зависимости и образ исполнения нужно отдельно зафиксировать перед официальным замером.

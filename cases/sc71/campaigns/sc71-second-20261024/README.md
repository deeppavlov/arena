- [start.md](start.md) — промпт отдельного запуска поиска после подтверждённой готовности.
- [Исходный промпт и ответы пользователя](../../../../archive/cases/sc71/campaigns/sc71-first-20261019/local-notes/prompt.md) — основание сохранённых условий.

Готовность прежней установки не является свидетельством готовности новой.

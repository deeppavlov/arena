# Данные SC-35

Кейс использует `sc-35-espd-unified-v1`: 881 вход, 1 067 ожидаемых замечаний, 28 контролей; Train/Public/Private — 113/128/640. Исходное разделение сохранено. Все варианты происходят от одной раскрытой ПМИ: holdout удерживает повреждения, а не независимые исходные документы.

Реальные JSONL хранятся у оператора вне Git и образов. Каждая строка содержит `id`, `input` (строка JSON с `case_id`, `docx_base64`, `document_sha256`, `text_sha256`) и `reference` (строка span-reference). Вход представляет полный DOCX; канонический текст восстанавливается одним зафиксированным extractor. Эталон решателю не передаётся.

Профиль из 99 нормативных и 14 редакционных правил и общая таксономия доступны всем решениям в `ways/baseline/assets`. `coverage.json` описывает обработчики и ограничения исходного baseline, а не доказанную полноту проверки. Неподтверждённая геометрия требует отдельного рендера и не превращается в доказанное нарушение по тексту.

Train открыт через штатный сервис и разрешённый канал данных. Public возвращает только общий score. Private возвращает только статус; его данные, ответы, оценки и результаты остаются у оператора. Генераторы повреждений, исходные GOLD и их инвентари не входят в пакет исследователя.

Экспорт от 28.10.2026 подтвердил размеры 113/128/640; максимальный `input` — 155 558 символов, `reference` — 3 530, оба ниже контрактного предела 500 000. Это техническая проверка упаковки, не оценка качества решения.

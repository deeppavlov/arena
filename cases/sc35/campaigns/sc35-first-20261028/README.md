# Кампания SC-35: первый запуск

Подготовка начата 28.10.2026 по команде пользователя перенести материалы `archive/local/sc-35-espd` в арену и подготовить запуск на GPU6 в контейнере Hermes по образцу SC-71. Этот каталог — явная точка входа новой кампании; подготовка не запускает поиск.

- [campaign.md](campaign.md) — задача, данные, метрика, условия модели, разрешённые изменения и отбор.
- [preparation.md](preparation.md) — фактическая готовность, версии образов, результаты проверок и оставшиеся ограничения.
- [metric/](metric/) — замороженный пакет, общий для train/public/private.
- [deploy/README.md](deploy/README.md) — отдельная установка на GPU6.
- [start.md](start.md) — промпт будущего поискового запуска по отдельной команде пользователя.

Установка использует `/cephfs/home/malyshev_sa/arena-sc35-first-20261028`; существующие кампании SC-71 сохраняются. Общая папка исследователей — `/workspace/cases/sc35/campaigns/sc35-first-20261028`, канонический журнал — её `search.sqlite3` на локальном Docker volume GPU6. Журнал, реальные данные, секреты и результаты исполнения остаются вне Git. Наличие этих файлов само по себе не подтверждает готовность: свидетельства находятся в `preparation.md`, а перед поиском повторяются живые проверки.

## Пакет и условия

Кейс перенесён из `archive/local/sc-35-espd`. Детерминированная сборка и экспорт воспроизвели 881 вход, 1 067 ожидаемых замечаний, 28 контролей и прежний split train/public/private 113/128/640. Пакет [metric/](metric/) имеет версию `sc35-span-unified-v1`, `kind=command`, направление `maximize`. Корпусная агрегация сначала суммирует символьные статистики по категориям, затем вычисляет macro F1; итог находится на шкале 0–100. Оценщик не использует LLM. `freeze` и `verify` прошли для девяти файлов; смысловые проверки выполнены отдельно на синтетических примерах.

Закреплены 100 предложенных решений, ровно 10 входных финалистов private и 3 итоговых решения. Генеративные роли используют внутреннюю `deepseek-ai/DeepSeek-V4-Flash-0731`, `reasoning_effort=max`; Hermes upstream `86fa9e6ca1de7ee71132d2be0103f3e37d1fa872`, профиль делегирования 30/30/3. MLflow обязателен. Поиск и реальные модельные эксперименты при подготовке не выполнялись.

## Отдельный запуск

По новой команде пользователя используется [prompts/start.md](../../../../prompts/start.md) с указанными кейсом и кампанией. Операторский launcher повторно проверяет сервисы, private gate, метрику и чтение полного MLflow payload до создания модельного доступа исследователя:

```bash
ssh gpu6 'bash /cephfs/home/malyshev_sa/arena-sc35-first-20261028/release/cases/sc35/campaigns/sc35-first-20261028/deploy/launch.sh'
```

Для просмотра исследовательского MLflow:

```bash
ssh -L 5054:127.0.0.1:5054 gpu6
```

После открытия туннеля интерфейс доступен на `http://localhost:5054`. Операторский MLflow со всеми закрытыми результатами остаётся на `5050` и исследователю не предоставляется.

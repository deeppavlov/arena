Модульные тесты выполнялись на Python 3.14; образ и его smoke — на Python 3.12. Starlette выдаёт одно предупреждение об устаревающей интеграции TestClient с httpx. Оно не влияет на результаты и не является ошибкой сервиса.

Контейнерный smoke проверил передачу текущего входа, подготовку контекста, обращение через реальный gateway к вымышленной модели, запрет другой модели, UID/GID 10001, отсутствие capabilities, no-new-privileges, readonly mounts, ограниченный tmpfs, отсутствие private/secrets/socket и модельного ключа у кандидата. Проверены остановка по таймауту и удаление временных контейнеров и сети. Скрипт воспроизводится так:

```bash
docker build --target evaluator -t arena-evaluator:check .
uv run python -m tests.docker_smoke --gateway-image arena-evaluator:check
```

Скрипт собирает runner и использует только вымышленные входы и временный fake upstream. Его успех не удостоверяет firewall, SSH-права и ACL неизвестного кластерного узла. Эти условия оператор проверяет перед подключением реальных данных по инструкции развёртывания. Полная кампания с выбранным продуктовым харнесом и доступность `gpu6:5050` в эту проверку не входят.

Проверены атомарный лимит предложенных решений, сохранение неудачных предков, восстановление снимков, запрет новых проверок после остановки и завершение уже начатых. Журнал является инструментом оркестратора: он не запускает процессы и не заменяет исполнитель. Для распределённой работы к журналу обращается общий координатор.

Сервис проверен на точные входные и выходные количества больше пяти, оба направления метрики, отрицательные оценки, вычисляемые метрики и агрегацию, пустые входы и эталоны. Public возвращает только score и повторно использует результат того же содержимого между пакетами; private возвращает только статус, включая повторную доставку и рестарт. Ресурсный порядок выбора сохранён, немодельные токены измеряются как ноль. Docker smoke подтвердил передачу параметров харнеса, отсутствие сети и модельных реквизитов у немодельной программы, сохранение пустого ответа и измерение времени снаружи контейнера.

Независимое ревью выявило и помогло устранить неполную фиксацию ID и порядка датасета, блокирование HTTP-запросов долгими проверками, ограничения на пустые входы и требование недоступных расходов public в журнале. Для этих ошибок добавлены регрессионные тесты. AUC дополнительно сверен независимым расчётом на 5000 случайных историй с обоими направлениями, отрицательными оценками, ошибками, асинхронными завершениями и разными горизонтами; расхождений не найдено.

Работа с конкретными сторонними харнесами, вычисляемыми метриками и кластерным доступом требует их операторской конфигурации по общему контракту. Проверки используют искусственные задачи и не подтверждают качество поиска на реальном кейсе. Существующее предупреждение Starlette о TestClient сохраняется.

## Исправления после перепроверки ревью

Проверено 17.10.2026. Все десять основных замечаний подтверждены кодом и регрессионными проверками. Исправления разрабатывались в отдельных worktree и прошли независимое ревью. Реальные модели, датасеты и MLflow не использовались. SHA-256 всех 107 исторических файлов `artifacts/` совпадают с исходными.

| Замечание | Исправление и проверка |
| --- | --- |
| 1. Доступ к чужому учёту по UUID | Независимый секрет запуска проверяется под блокировкой до чтения тела и изменения учёта. Docker подтвердил отказ по чужому секрету и старому URL, неизменные расходы и возможность закрытия записи. |
| 2. Потерянные предложения | Транспортные пределы не ограничивают локальный снимок. Ошибки безопасного снимка, включая неподдерживаемые имена файлов, сохраняются вместе с местом в бюджете, расходами и родителями. |
| 3. Очередь public после остановки | Public принимает одного кандидата; отдельный работник стартует до `202`. Проверены отклонение пакета и запуск при занятом общем executor. Private сохраняет пакет точного размера. |
| 4. Невалидная конфигурация судьи | Статическая проверка до сохранения допуска; запрещённые параметры, неверные endpoint и порты отвергаются при создании приложения. |
| 5–6. Права и идентичность снимка | Новые снимки и private используют общую форму файлов; executable bits входят в digest. Docker проверил восстановление под локальным UID 1000 и запуск под UID 10001, включая исполняемый helper. Старые снимки сохраняют архивные каталоги и права. |
| 7–8. Импорты и пустой вход | Многофайловые `solve.py` и `prepare.py` поддерживают соседние модули. Пустой и пробельный вход передаются модели без изменения; проверки используют подставной upstream. |
| 9. Дочерние процессы метрики | Проверены завершение группы и ожидание остановки при таймауте, ошибке и успешном выходе команды. |
| 10. Диагностика метрики | Ограниченные stdout/stderr и сведения о завершении сохраняются в закрытых журналах примера, агрегатора и всей проверки. Public/private API не раскрывают их. |

Формула AUC сохранена. Экспорт добавляет `final_quality`; документация объясняет зависимость AUC от порядка предложений и параллелизма. Непредставимый конечным числом интеграл вызывает явную ошибку. Для score определён контракт binary64: целые типы и целые JSON-токены вне `±(2**53 - 1)` отклоняются до округления; дробные и экспоненциальные записи приближённые.

Подтверждена уязвимость учёта, но не утечка private. Очистка процессов рассчитана на доверенную метрику, чьи потомки остаются в исходной группе. Совместимость произвольного стороннего харнеса и native tool calling не заявляется: адаптер должен выполнять общий контракт. Существующее предупреждение Starlette о TestClient сохраняется.

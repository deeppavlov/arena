Модульные тесты выполнялись на Python 3.14; образ и его smoke — на Python 3.12. Starlette выдаёт одно предупреждение об устаревающей интеграции TestClient с httpx. Оно не влияет на результаты и не является ошибкой сервиса.

Контейнерный smoke проверил передачу текущего входа, подготовку контекста, обращение через реальный gateway к вымышленной модели, запрет другой модели, UID/GID 10001, отсутствие capabilities, no-new-privileges, readonly mounts, ограниченный tmpfs, отсутствие private/secrets/socket и модельного ключа у кандидата. Проверены остановка по таймауту и удаление временных контейнеров и сети. Скрипт воспроизводится так:

```bash
docker build --target evaluator -t arena-evaluator:check .
uv run python -m tests.docker_smoke --gateway-image arena-evaluator:check
```

Скрипт собирает runner и использует только вымышленные входы и временный fake upstream. Его успех не удостоверяет firewall, SSH-права и ACL неизвестного кластерного узла. Эти условия оператор проверяет перед подключением реальных данных по инструкции развёртывания. Полная кампания с выбранным продуктовым харнесом и доступность `gpu6:5050` в эту проверку не входят.

## Длительные запуски, повторы и замеры ресурсов

Проверено 14.10.2026. Реальные модели, датасеты, MLflow и кластер не использовались.

| Проверка | Результат |
| --- | --- |
| `uv run ruff check .` | Пройдена |
| `uv run pyright` | 0 ошибок и предупреждений |
| `uv run pytest -q` | 445 тестов пройдены |
| `uv run python -m evaluator.smoke` | Пройден |
| Compose с обоими профилями и примером env | Конфигурация валидна |
| Образ evaluator и комплектный runner | Собраны локально |
| `uv run python -m tests.docker_smoke --gateway-image arena-evaluator:check` | Пройден с подставным upstream |
| Markdown-ссылки и синтаксис Python-примеров | Проверены |

Тесты покрывают первоначальный запрос и пять повторов без вложенного умножения попыток, ошибки транспорта и формата ответа, валидацию судейских голосов, обязательный usage, неизвестный расход и сохранение замеров при сбоях. Проверены порядок выбора при равном качестве, отдельный учёт решателя и судьи, закрытие журнала после завершения и прекращение новых повторов после остановки runner. Docker smoke дополнительно проверяет передачу параметров подготовки, фактический расход через gateway, недоступность журнала кандидату и сохранение изоляции контейнера.

Многочасовой модельный запуск не выполнялся: значения таймаутов и их передачу проверяют тесты, ожидания повторов подменены. Правила сна исследователя и глубины субагентов являются инструкциями выбранному агентному исполнителю; его реальные ограничения и многодневное сохранение сессии здесь не проверялись. Предупреждение Starlette о TestClient остаётся прежним.

не использовались.

Модульные тесты выполнялись на Python 3.14; образ и его smoke — на Python 3.12.
Starlette выдаёт одно предупреждение об устаревающей интеграции TestClient
с httpx. Оно не влияет на результаты и не является ошибкой сервиса.

Контейнерный smoke проверил передачу текущего входа, подготовку контекста,
обращение через реальный gateway к вымышленной модели, запрет другой модели,
UID/GID 10001, отсутствие capabilities, no-new-privileges, readonly mounts,
ограниченный tmpfs, отсутствие private/secrets/socket и модельного ключа у
кандидата. Проверены остановка по таймауту и удаление временных контейнеров
и сети. Скрипт воспроизводится так:

```bash
docker build --target evaluator -t arena-evaluator:check .
uv run python -m tests.docker_smoke --gateway-image arena-evaluator:check
```

Скрипт собирает runner и использует только вымышленные входы и временный fake
upstream. Его успех не удостоверяет firewall, SSH-права и ACL неизвестного
кластерного узла. Эти условия оператор проверяет перед подключением реальных
данных по инструкции развёртывания. Полная кампания с выбранным продуктовым
харнесом и доступность `gpu6:5050` в эту проверку не входят.

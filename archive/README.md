# Архив

Здесь хранятся исторические отчёты и материалы, которые не нужны для запуска арены. Архив не читается автоматически при подготовке или поиске и не подтверждает текущую готовность кода или развёртывания.

| Каталог | Содержимое |
| --- | --- |
| [development/](development/verification.md) | Датированный журнал проверок разработки и другие отчёты об изменениях |
| [cases/sc71/campaigns/sc71-first-20261019/](cases/sc71/campaigns/sc71-first-20261019/README.md) | Исторические свидетельства подготовки и работы первой кампании SC-71 |
| `local/artifacts/` | Локальные исследования, заметки и исходные материалы |
| `local/runs/` | Два исторических каталога проверок разработки от 17 октября 2026 года |

`local/` исключён из Git и остаётся только в рабочей копии. Действующие кампании, их канонические журналы и используемые пакеты остаются на своих рабочих путях. Исходные пути внутри сохранённых свидетельств описывают прежнее размещение и не являются инструкцией для нового запуска.

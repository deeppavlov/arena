# Общий MLflow proxy и регрессия крупных артефактов

Первоначальное исправление OOM операторского MLflow было сохранено в исходниках SC35, но другие Compose продолжали подключать прежний конфиг SC71. Раздельные копии позволяли новым установкам воспроизвести ту же ошибку. 28 октября 2026 года конфигурация объединена в [deploy/mlflow/operator-nginx.conf](../../deploy/mlflow/operator-nginx.conf), подключённый всеми тремя существующими Compose. Две кейсовые копии удалены. Память, HTTP-лимит, сетевые ограничения и очистка Authorization сохранены.

[tests/test_mlflow_deploy.py](../../tests/test_mlflow_deploy.py) проверяет фактически разрешённые Docker Compose пути readonly mount и инвентарь потребителей. До переноса три проверки mount падали; после переноса все четыре проверки прошли. Новый Compose с операторским nginx потребует включения в этот набор.

[tests/mlflow_proxy_smoke.py](../../tests/mlflow_proxy_smoke.py) — отдельная поведенческая регрессия настоящего nginx с лимитом памяти 128 MiB без swap. Синтетический сервер и клиент работают в собственной внутренней Docker-сети; настоящие MLflow, модели, датасеты и кампании не используются. Проверяются chunked upload 160 MiB, чтение ответа с задержкой, точное совпадение данных, Host, удаление Authorization и счётчики ограничения памяти cgroup v1/v2. Стенд удаляет только собственные контейнеры и сеть.

| Конфигурация | Результат |
| --- | --- |
| Прежний конфиг SC71 из ревизии `c7333ba` | Загрузка обрывается, nginx `OOMKilled=true`, exit 137 |
| Исправленный конфиг без одной директивы `proxy_buffering off` | OOM при чтении ответа, nginx exit 137 |
| Общий исправленный конфиг | Загрузка и чтение 167 772 160 байт, точное совпадение; все memory events равны нулю, 4,906 секунды |

Сценарии выполнены в отдельном worktree `/tmp/arena-mlflow-regression-20261028` с локальными образами `nginx:1.28-alpine` и `python:3.12-slim`, после чего проверенный файл перенесён в основную рабочую копию. Команды для дальнейшей приёмки включены в [инструкцию proxy](../../deploy/mlflow/README.md) и RPD. Это дополнительная контейнерная проверка при изменении proxy; обычный pytest проверяет подключение общего файла, но не требует запуска Docker-контейнеров.

После интеграции прошли `uv run ruff check .`, `uv run pyright` с нулём ошибок и предупреждений, `uv run pytest` — 1633 теста за 61,54 секунды, `uv run python -m evaluator.smoke`, 32 теста SC35 за 2,74 секунды и 177 тестов SC71 за 8,98 секунды. В общем pytest осталось одно прежнее предупреждение StarletteDeprecationWarning об httpx. Коммитов нет.

В 18:46:47 МСК установка SC35 на GPU6 переведена на общий readonly mount: пересоздан только операторский proxy с тем же образом и побайтово идентичным исправленным конфигом. `nginx -t` прошёл до и после применения; остальные десять контейнеров сохранили ID, время старта, образ и счётчики рестартов. Свежий цикл монитора в 18:48:24 МСК подтвердил семь исправных очередей без ожидающих записей и ошибок. Неиспользуемые кейсовые копии внутри SC35 release сохранены в операторском backup и удалены; live-установки SC71 не менялись. [Серверное свидетельство](../cases/sc35/campaigns/sc35-first-20261028/evidence/mlflow-common-config-20261028.json) подтверждает завершённую миграцию без отложенного пересоздания.

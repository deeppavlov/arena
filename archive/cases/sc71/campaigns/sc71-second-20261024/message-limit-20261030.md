# Предел истории gateway: 10 000 сообщений

30 октября пользователь поручил поднять предел истории с 1000 до 10 000 сообщений. В `ModelRequest.messages` изменена только верхняя граница; ограничение тела запроса по умолчанию 16 MiB сохранено. Тесты проверяют передачу 1001 и 10 000 сообщений без усечения и отказ на 10 001 без обращения к модели.

Причина остановки исследователя 30 октября в 09:42 МСК воспроизведена на установленном образе: последний успешный запрос содержал 999 сообщений; сообщение ассистента с вызовом инструмента и результат инструмента увеличивают историю до 1001. Прежний gateway возвращает HTTP 400 до модельного вызова и записи трейса. Сам отклонённый запрос не был сохранён; проверка выполнена с сохранённой историей и синтетическим результатом инструмента. Увеличение пауз повторов само по себе этот отказ не устраняет.

Пакет содержит исходник, Dockerfile, отдельный Compose override и свидетельство проверки. При следующем возобновлении этот override заменяет override из [пакета повторов](retry-window-20261028.md); остальные шаги сохранения состояния и проверки готовности прежние.

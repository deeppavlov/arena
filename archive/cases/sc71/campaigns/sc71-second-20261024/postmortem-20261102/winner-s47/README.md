## Как работает решение

Python строит индекс и выполняет текстовый поиск BM25. Модель формулирует запросы, читает найденные исходные документы, сопоставляет нормы и пишет ответ. Затем она вызывает инструменты проверки цитат и ссылок и по инструкции исправляет найденные ошибки. В пакет входят сам метод, его промпт и инструменты; база документов, Hermes и веса модели подключаются отдельно.

Отличие S47 от S31 — один абзац промпта: после 3–4 разных поисковых запросов, если новые запросы перестали приносить новые релевантные документы, переходить к чтению и ответу. Это мягкое правило остановки бесполезного поиска; жёсткого ограничения в четыре вызова нет. Настройка модели не менялась: `deepseek-ai/DeepSeek-V4-Flash-0731`, `reasoning_effort=max`.

Для понимания и переноса метода достаточно исходников и описания. Для воспроизведения полных ответов нужны исходная KB кампании, адаптер `cases/sc71/harness/hermes/`, закреплённая версия Hermes и доступ к той же внутренней модели. Инструменты подготовки, поиска и проверки работают без LLM; их синтетическая проверка прошла. Повторного измерения качества при извлечении не проводилось.

Описанные в `ALGORITHM.md` особенности сохранённого кода, включая порядок отбора фрагментов, оставлены как в измеренном победителе. Исправление или перенос с изменением поведения будет отдельной версией решения.
